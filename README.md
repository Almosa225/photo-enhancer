# محسّن الصور

تطبيق أندرويد يحسّن الصور تلقائياً: يكبّرها بالذكاء الاصطناعي لدقة 8K، ويضبط الألوان والتباين والوضوح. كل المعالجة تصير على الجوال نفسه.

## التحميل
افتح صفحة **Releases** في هذا المستودع، وحمّل أحدث نسخة من ملف `photo-enhancer.apk`.

## كيف ينبني التطبيق
- الواجهة في مجلد `www/`، والذكاء الاصطناعي يشتغل بـ TensorFlow.js مع نموذج ESRGAN.
- التطبيق مبني بـ Capacitor، ومشروع أندرويد في مجلد `android/`.
- مع كل push على `main` يبني GitHub Actions ملف الـ APK تلقائياً وينشره في Releases.
